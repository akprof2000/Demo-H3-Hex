# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [семантические](https://semver.org/lang/ru/): MAJOR.MINOR.PATCH.

## [0.5.0] — 2026-08-07

### Добавлено

- **Клик по гексагону копирует его индекс в буфер обмена** и показывает
  всплывающее подтверждение. Управляется пропсами `copyOnClick` (по умолчанию
  включено), `copyToast` и `onCopy`.
- Запасной путь копирования через `document.execCommand` для незащищённого
  контекста: `navigator.clipboard` доступен только по https и на localhost.

## [0.4.0] — 2026-08-07

### Добавлено

- **Настраиваемая толщина линий**: пропсы `lineWidth` (по умолчанию **2 CSS-пикселя**)
  и `highlightWidth` (по умолчанию на пиксель толще сетки), метод слоя `setWidth`.
  Толщина считается в вершинном шейдере, поэтому её смена не перестраивает
  геометрию — это один кадр при любом числе гексагонов.
- В демо появился ползунок толщины.
- Иконка вкладки (`public/favicon.svg`) — раньше браузер получал 404.

### Изменено

- Линии рисуются треугольниками (`gl.drawElements`) вместо `gl.LINES`:
  `gl.lineWidth` больше 1 не работает ни в Chrome, ни в Edge на Windows.
  Экспортированы `expandSegments` и `loopToSegments` для своих слоёв.

## [0.3.0] — 2026-08-07

### Изменено

- **Цвет сетки по умолчанию стал чёрным** (`rgba(0,0,0,0.45)`) вместо белого:
  растровые тайлы OSM светлые, тёмная линия на них читается лучше. Для тёмной
  подложки передайте светлый цвет: `<H3Grid color="#ffffff59" />`.

### Добавлено

- В демо появился вариант «Чёрная» и выбран по умолчанию.

## [0.2.1] — 2026-08-07

### Изменено

- В README и обоих руководствах появились ссылки на живое демо с пояснением,
  какая вкладка какому компоненту соответствует.
- Релиз собирается через `gh` CLI вместо `softprops/action-gh-release@v2`:

## [0.2.0] — 2026-08-07

### Добавлено

- **`H3Grid`** — компонент, закрашивающий весь экран границами гексагонов H3
  заданного разрешения. Данных не требует: список ячеек вычисляется из видимой
  области карты.
- **`H3GridLayer`** — облегчённый WebGL-слой MapLibre: только линии, вся сетка
  экрана за один вызов отрисовки, цвет меняется без перестроения геометрии.
- **`gridGeometry`** — чистые функции без React и WebGL (`cellsForBBox`,
  `buildGridMesh`, `estimateCellCount`, `padBBox`, `resolutionForEdgePixels`);
  переносятся в Web Worker как есть.
- Автоподбор разрешения по зуму: ребро гексагона держится около
  `targetEdgePixels` пикселей на любом масштабе.
- Предохранитель `maxCells`: перед построением считается дешёвая оценка числа
  ячеек, слишком мелкая сетка на большой области просто не строится.
- Демо на OpenStreetMap с переключателем «Сетка гексагонов» / «Тепловая карта».
- Руководство [docs/GRID.md](docs/GRID.md).

### Изменено

- Прежнее демо `H3Map` переехало из `example/App.tsx` в `example/HeatDemo.tsx`;
  `App.tsx` стал переключателем между двумя примерами.

## [0.1.0]

### Добавлено

- `H3Map` — карта OpenStreetMap (MapLibre GL) со слоем гексагонов H3 на GPU.
- Дискретная и непрерывная палитры, готовая `RSRP_PALETTE`, легенда с долями.
- Подгрузка данных по вьюпорту, сборка меша в Web Worker, адаптивная обводка.
