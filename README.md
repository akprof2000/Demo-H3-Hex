# react-h3-map — Demo H3 Hex 🗺️

Маленькая быстрая React-библиотека: карта OpenStreetMap (MapLibre GL) + слой гексагонов H3,
отрисованный на GPU **одним draw call**.

Зависимости — только `react`, `maplibre-gl`, `h3-js` (все в peerDependencies). Никакого deck.gl.

**▶️ [Живое демо](https://akprof2000.github.io/Demo-H3-Hex/)** — две вкладки:
«Сетка гексагонов» (`H3Grid`) и «Тепловая карта» — покрытие RSRP по Москве,
разрешение H3 от 6 до 14 по зуму.

**📖 [Подробное руководство](docs/GUIDE.md)** — как всё устроено внутри и что менять под себя.
Весь исходный код прокомментирован построчно на русском.

**🕸️ [Руководство по `H3Grid`](docs/GRID.md)** — отдельный компонент, который закрашивает
весь экран границами гексагонов H3 заданного разрешения (без данных, только сетка):

```tsx
import { H3Grid } from 'react-h3-map';

<H3Grid resolution="auto" targetEdgePixels={40} color="#22d3eeaa" />;
```

**📋 [История изменений](CHANGELOG.md)** — версии семантические, релизы собираются
GitHub Actions по тегу `v*` (workflow [`release.yml`](.github/workflows/release.yml)).

## Установка

```bash
npm i react-h3-map maplibre-gl h3-js
```

В точке входа приложения подключите стили MapLibre:

```ts
import 'maplibre-gl/dist/maplibre-gl.css';
```

## Формат данных

Бэкенд отдаёт компактный массив пар — индекс H3 и числовое значение:

```json
[["891fb46622fffff", 42.5], ["891fb46627bffff", 17.0]]
```

Цвет считает фронт: значение → палитра (`ColorScale`), одна интерполяция при построении
таблицы поиска, дальше на гексагон — одно обращение к LUT.

Палитра бывает двух видов:

- **непрерывная** — список опорных цветов в `colors`, между ними интерполяция;
- **дискретная** — диапазоны в `bins`, цвет берётся целиком по диапазону.
  Для радиопокрытия есть готовая `RSRP_PALETTE` со стандартными порогами
  (−70…0 синий, −90…−70 тёмно-зелёный, … , −200…−118 чёрный). В этом режиме
  легенда показывает список диапазонов и долю ячеек в каждом.

```tsx
import { H3Map, RSRP_PALETTE } from 'react-h3-map';

<H3Map palette={RSRP_PALETTE} domain={[-200, 0]} fetchData={fetcher} />;
```

## Быстрый старт

```tsx
import { H3Map } from 'react-h3-map';

<H3Map
  data={[['891fb46622fffff', 42.5]]}
  center={[37.6173, 55.7558]}
  zoom={11}
/>;
```

## Подгрузка по вьюпорту

```tsx
<H3Map
  fetchData={async (vp, signal) => {
    const r = await fetch(
      `/api/hexes?bbox=${vp.bbox.join(',')}&res=${vp.resolution}`,
      { signal }
    );
    return r.json(); // [[h3, value], ...]
  }}
  resolutionForZoom={(z) => Math.min(14, Math.max(6, Math.round(z) - 3))}
  debounceMs={200}
  onClick={(info) => console.log(info?.h3, info?.value)}
/>
```

`fetchData` вызывается на `moveend`/`zoomend` с дебаунсом; предыдущий запрос отменяется
через `AbortSignal`, ответы, пришедшие не по порядку, отбрасываются.

## Пропсы

| Проп | Описание |
| --- | --- |
| `data` | Готовый массив `[[h3, value], ...]`. Взаимоисключим с `fetchData`. |
| `fetchData` | `(viewport, signal) => Promise<H3Cell[]>` — подгрузка по вьюпорту. |
| `resolutionForZoom` | Своё соответствие зума и разрешения H3. |
| `palette` | `{ colors, opacity }` — цвета шкалы от min к max. |
| `domain` | Фиксированный диапазон значений; по умолчанию min/max по данным. |
| `center`, `zoom`, `minZoom`, `maxZoom` | Начальный вид. |
| `mapStyle` | URL или объект стиля MapLibre. По умолчанию растровый OSM. |
| `stroke` | Обводка: `false`, либо `{ color, thresholds, mode }`. По умолчанию адаптивная. |
| `workerThreshold` | Порог (в ячейках), выше которого меш строится в Web Worker. По умолчанию 20 000. |
| `workerFactory` | Своя фабрика воркера, если сборщик не резолвит путь сам. |
| `onHover`, `onClick` | Колбэки с `{ h3, value, lng, lat, x, y }`. |
| `tooltip` | `false` или свой рендер `(info) => ReactNode`. |
| `legend` | `false` или `{ title, format }`. |

## Как это устроено

- **Геометрия.** `cellToBoundary` → Web-Mercator → триангуляция веером (гексагон выпуклый,
  earcut не нужен). Один интерливленный набор буферов: `Float32` позиции, `Uint8` цвета,
  `Uint32` индексы.
- **Точность.** Позиции хранятся относительно origin-точки; сдвиг вносится в матрицу в
  двойной точности, поэтому на z16+ вершины не «плывут».
- **Пикинг — на CPU.** Вместо второго прохода рендера в offscreen-буфер берём `lngLat` курсора,
  считаем `latLngToCell` в разрешениях, встреченных в данных, и ищем в `Map`. Это O(1) и не
  стоит ни одного лишнего кадра.
- **Антимеридиан.** Долготы вершин нормализуются относительно первой, полигон не рвётся.
- **Адаптивная обводка.** Крупные гексы (ребро ≥ 14 px) — вся сетка; средние (4…14 px) —
  только границы между разными цветами, посчитанные топологически через directed edges;
  мелкие — без линий, иначе карта превращается в рябь.
- **Web Worker.** Свыше 20 000 ячеек геометрия строится в фоновом потоке, буферы
  возвращаются через transferable — без копирования.

### Измеренная производительность (Chrome, dev-сборка)

| Гексагонов | Сборка меша | Память буферов |
| --- | --- | --- |
| 1 300 | ~2 мс | 0.2 МБ |
| 100 000 | ~250 мс | 14 МБ |

Отрисовка при этом — один `drawElements` на кадр независимо от количества гексагонов.

## Демо

Демо по Москве с разрешением H3 от 6 (город целиком) до 14 (отдельный дом), фейковым
бэкендом, переключением палитр и счётчиком гексагонов:

```bash
npm install
npm run dev
```

Открыть http://localhost:5180. Переключатель вкладок — `example/App.tsx`,
тепловая карта — `example/HeatDemo.tsx` (мок-эндпоинт в `example/mockBackend.ts`),
сетка — `example/GridDemo.tsx`.

То же самое без установки — в [живом демо](https://akprof2000.github.io/Demo-H3-Hex/).

## Лицензия и тайлы

По умолчанию используются тайлы `tile.openstreetmap.org` — они годятся для разработки,
но их [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) запрещает
серьёзный продовый трафик. В проде передайте свой источник:

```tsx
import { osmStyle } from 'react-h3-map';
<H3Map mapStyle={osmStyle(['https://tiles.example.com/{z}/{x}/{y}.png'])} />
```
